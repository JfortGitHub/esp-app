# Нормативы ЭСП — Серверная версия

Многопользовательская система нормативов трудозатрат для цеха.
Все данные хранятся в единой базе на сервере — сотрудники видят изменения друг друга в реальном времени.

## 🚀 Быстрый старт

### Требования

- Docker 20.10+ и Docker Compose v2
- Свободный порт 3000 на сервере

### Установка (Linux / Windows с Docker Desktop)

```bash
git clone https://github.com/JfortGitHub/esp-app.git
cd esp-app
docker compose up -d
